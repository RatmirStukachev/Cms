# Инструкция по развертыванию Django CRM на ISPmanager (hoster.by)

Мы подготовили наш проект для работы в Production-среде (на рабочем сервере). Мы добавили файл `passenger_wsgi.py`, настроили раздачу статики через библиотеку `whitenoise` и скрыли секретные ключи.

Ниже приведена пошаговая инструкция, как загрузить и запустить этот проект на вашем хостинге c панелью ISPmanager:

## Шаг 1: Подготовка домена и Python-приложения
1. Зайдите в панель управления ISPmanager на вашем хостинге (hoster.by).
2. Перейдите в раздел **WWW-домены** (или просто **Сайты**) и нажмите **Создать**.
   - Доменное имя: `crm.perf.by`
   - Псевдонимы: (можно оставить пустым или указать `www.crm.perf.by`)
   - Корневая папка: обычно создается автоматически (например, `www/crm.perf.by` или `public_html/crm.perf.by`).
   - Если есть галочка **Python** или **CGI**, убедитесь, что она включена (в ISPmanager поддержка Python часто настраивается отдельно в разделе **Web-сервер** -> **Python** или созданием веб-приложения).
3. (Альтернативно, если на хостинге используется **CloudLinux** с функцией **Setup Python App**):
   - Перейдите в раздел **Setup Python App** (Настройка Python-приложений).
   - Нажмите **Create Application** (Создать приложение).
   - **Python version**: выберите 3.10 или 3.11.
   - **Application root**: `crm.perf.by` (папка, куда мы загрузим файлы).
   - **Application URL**: `crm.perf.by`
   - **Application startup file**: `passenger_wsgi.py` (мы его уже создали в проекте).
   - **Application Entry point**: `application`
   - Нажмите **Create** (Создать).

## Шаг 2: Загрузка файлов
1. Упакуйте все файлы нашего проекта (папку `crm_project`, `store_crm`, файлы `manage.py`, `requirements.txt`, `passenger_wsgi.py` и базу данных `db.sqlite3` если хотите перенести текущие данные) в ZIP-архив.
2. В ISPmanager перейдите в **Менеджер файлов** и откройте папку вашего приложения (которую мы указали как Application root).
3. Нажмите **Закачать** и загрузите ваш ZIP-архив.
4. Выделите архив и нажмите **Извлечь**. Файлы должны оказаться прямо в корневой папке приложения (рядом с автоматически созданным `passenger_wsgi.py`, если хостинг его создал — наш файл должен его перезаписать).

## Шаг 3: Настройка окружения (Переменные среды)
В целях безопасности мы вынесли секретные данные в переменные окружения.
В разделе **Setup Python App** (или в файле `.env`, если используете другой способ):
1. Найдите раздел **Environment variables** (Переменные окружения) для вашего приложения.
2. Добавьте следующие переменные:
   - Имя: `DJANGO_SECRET_KEY`
     Значение: *(придумайте длинную случайную строку, например: `d&x3j23!k_c8v38...`)*
   - Имя: `EMAIL_HOST_USER`
     Значение: `ваш_email@gmail.com`
   - Имя: `EMAIL_HOST_PASSWORD`
     Значение: `ваш_пароль_приложения_google` (тот, что вы сгенерировали ранее)

## Шаг 4: Установка зависимостей
1. В разделе **Setup Python App** для вашего приложения найдите блок **Configuration files** (Конфигурационные файлы).
2. Введите `requirements.txt` и нажмите **Add**.
3. Нажмите кнопку **Run Pip Install** (Запустить Pip Install). Хостинг сам установит Django, whitenoise и другие нужные пакеты.

*(Альтернативный способ через SSH/Терминал)*:
Если у вас есть доступ по SSH, вы можете зайти в папку проекта, активировать виртуальное окружение, которое создал хостинг, и запустить:
`pip install -r requirements.txt`

## Шаг 5: Применение миграций и сбор статики
Поскольку мы используем базу данных `db.sqlite3`, вы можете просто загрузить её вместе с файлами.
Но для правильной работы статики (CSS, JavaScript из админки и Bootstrap) нужно собрать статику.

Если у вас есть SSH (или терминал в панели управления):
1. Зайдите в терминал.
2. Перейдите в папку проекта: `cd /путь/к/вашей/папке/crm.perf.by`
3. Активируйте виртуальное окружение (команда для активации обычно написана в самом верху страницы настроек Python App, она выглядит примерно как `source /home/user/virtualenv/crm.perf.by/3.10/bin/activate`).
4. Выполните команду для сбора статики:
   `python manage.py collectstatic --noinput`
*(Это создаст папку `staticfiles`, откуда whitenoise будет отдавать стили).*
5. Выполните команду миграций (на всякий случай):
   `python manage.py migrate`

## Шаг 6: Запуск (Перезапуск) приложения
1. Вернитесь в **Setup Python App**.
2. Нажмите кнопку **Restart** (Перезапустить) напротив вашего приложения.

## Шаг 7: Настройка SSL сертификата
1. В ISPmanager перейдите в **SSL-сертификаты** -> **Let's Encrypt** и выпустите бесплатный сертификат для `crm.perf.by`.
2. Перейдите в настройки **WWW-доменов**, выберите `crm.perf.by` -> **Изменить** и поставьте галочку "Защищенное соединение (SSL)" и "Перенаправлять HTTP-запросы в HTTPS".

## Готово!
Теперь ваша CRM система должна быть доступна по адресу `https://crm.perf.by`. Вы можете зайти под своим логином суперпользователя и начать работу.
